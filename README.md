# DeepSeek Harness Desktop

Полноценное десктоп-приложение (стиля Claude Code / ChatGPT / Google Gemini) на базе [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness).

Работает на **Windows, Linux, macOS**. Это Electron-оболочка с React-интерфейсом, которая объединяет несколько LLM-провайдеров в одном приложении с локальной историей чатов, зашифрованным хранением ключей API и возможностью запуска локальных моделей Hugging Face.

---

## Возможности

| Возможность | Описание |
|-------------|----------|
| **Много провайдеров** | DeepSeek, OpenAI, Anthropic (Claude), Google (Gemini), Groq, Together, OpenRouter, Hugging Face (API + локально) |
| **Локальные ключи API** | Ключи вводятся один раз и хранятся зашифрованно (AES-256-GCM) на вашем компьютере в `userData` |
| **Локальные модели HF** | Запуск моделей Hugging Face локально через встроенный рантайм (Transformers.js / llama.cpp) |
| **Стриминг ответов** | Ответы модели приходят по токену в реальном времени |
| **История чатов** | Сессии и сообщения сохраняются локально (IndexedDB), доступны после перезапуска |
| **Маркдаун + код** | Отрисовка сообщений с подсветкой кода, формулами и вложениями |
| **Автообновление** | Проверка и установка новых версий через `electron-updater` |
| **Установщики** | Windows (NSIS `.exe`), macOS (`.dmg` / `.zip`), Linux (`.AppImage` / `.deb`) |

## Быстрый старт

### Предварительные требования

- Node.js 24.9+
- pnpm 11.28.5 (через Corepack)
- Git 2.26+

### Установка зависимостей

```bash
git clone https://github.com/Chistovik92/Harness.git
cd Harness
cd apps/desktop-app
npm install   # или pnpm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Запускает Vite dev server + Electron. Откроется окно приложения с hot-reload интерфейса.

### Сборка

```bash
npm run build
```

Собирает React-интерфейс (Vite) и Electron main-процесс в `dist/`.

### Установщики (релизные артефакты)

```bash
# Windows x64 (требуется Windows)
npm run package:win

# macOS (требуется macOS; Apple Silicon или Intel)
npm run package:mac

# Linux (требуется Linux)
npm run package:linux

# Все платформы сразу (требуется мультиплатформенный раннер)
npm run package:all
```

Готовые файлы appear в `release/`.

## Конфигурация

### API-ключи

При первом запуске откройте раздел **«Провайдеры API»** и добавьте ключ для нужного провайдера:

- **DeepSeek** — `https://platform.deepseek.com/apiKeys`
- **OpenAI** — `https://platform.openai.com/api-keys`
- **Anthropic** — `https://console.anthropic.com/`
- **Google** — `https://makersuite.google.com/app/apikey`
- **Hugging Face** — `https://huggingface.co/settings/tokens`

Ключи хранятся **только локально** в зашифрованном виде и никогда не передаются третьим лицам, кроме выбранного вами провайдера при отправке запроса.

### Локальные модели Hugging Face

Откройте **«Локальные модели»** в боковой панели: поиск на Hugging Face или скачивание **любой** модели по id (`org/name`) — без API-ключа, с прогрессом, докачкой после обрыва, отменой и удалением. Затем выберите провайдера **«Hugging Face (Локально)»** и скачанную модель.

Два формата:
- **GGUF (рекомендуется)** — движок llama.cpp (`node-llama-cpp`, GPU через Vulkan/Metal). Тысячи моделей, выбор квантизации (Q4_K_M — хороший баланс), **поддержка режима агента**. Хранится в `userData/gguf`.
- **ONNX** — `@huggingface/transformers`, небольшие модели (`HuggingFaceTB/SmolLM2-*`, `onnx-community/*`). Хранится в `userData/hf-cache`.

Всё работает **полностью локально** в отдельном Worker-потоке; ответы стримятся по токену. Большие модели (7B+) требуют много памяти — у каждой модели в интерфейсе указана оценка нужной ОЗУ.

**Вход в аккаунт Hugging Face** (кнопка на странице моделей, OAuth + PKCE, пароль приложение не видит) открывает закрытые модели (Llama, Gemma и др. после принятия условий) и облачные модели Hugging Face без ручного API-ключа. Токен хранится зашифрованно.

### Профили моделей

Для каждой модели (локальной, из поиска и облачной) показываются: качество **русского языка**, сильные стороны (диалог, тексты, код, математика, рассуждения, инструменты агента, изображения, аудио), размер, контекст, лицензия и нужная память. Это **оценка** по семейству модели, её размеру и метаданным Hugging Face (карточки часто указывают только `en`), а не результат бенчмарка.

### Режим агента

Галочка **«Режим агента»** в боковой панели даёт модели окружение, как у Claude Code/Codex: чтение, поиск и правка файлов, команды в терминале, загрузка веб-страниц и файлов, работа по **SSH/SFTP** (раздел «SSH-подключения»). Сетевые диски (`\сервер\папка`) работают как обычные пути. Работает с моделями API (DeepSeek, OpenAI, Anthropic, Google, Groq…) и локальными GGUF; ONNX-модели в режиме агента не поддерживаются. Маленькие модели (до ~3 млрд) вызывают инструменты ненадёжно.

Права доступа (выбираются в панели):
- **Авто в рабочей папке** (по умолчанию): чтение, поиск, правка и безопасные команды внутри выбранной папки выполняются сами; всё, что выходит за её пределы, рискованные команды (`sudo`, `git push`, удаление, установка настроек), обращения к внутренним адресам и любые действия на удалённых серверах спрашивают разрешение.
- **Спрашивать всё** и **Всё автоматически** (рискованно).

Ограничения: проверка команд эвристическая и не заменяет изоляцию (песочницу); не выбирайте «Всё автоматически» для недоверенных моделей. Загруженные страницы и файлы могут содержать инструкции, направленные на модель (prompt injection): проверяйте запросы разрешений, особенно после веб-запросов. Пароли и ключи SSH моделям не показываются, отпечаток ключа сервера запоминается при первом входе.

## Архитектура

```
apps/desktop-app/
├── src/
│   ├── electron/
│   │   ├── main.ts          # Основной процесс: окна, трей, IPC, автообновление, шифрование ключей
│   │   └── preload.ts       # Мост между main и рендерером (contextBridge)
│   └── renderer/
│       ├── App.tsx          # Главный чат-интерфейс
│       ├── ProvidersPage.tsx# Управление провайдерами и ключами API
│       ├── SettingsPage.tsx # Общие настройки
│       ├── context/         # React Context: DshContext, ChatContext
│       ├── lib/             # Провайдеры LLM, шифрование, IndexedDB-хранилище
│       └── index.html
├── resources/               # Иконки,’entitlements, LICENSE
├── electron-builder.json    # Конфигурация сборки installers (NSIS/DMG/AppImage)
├── vite.config.ts           # Vite конфиг
├── tailwind.config.js       # Стили
└── package.json
```

## CI/CD и релизы

Сборка и публикация автоматизированы через GitHub Actions:

- **Windows** — NSIS инсталятор `.exe` (подпись EV-сертификатом, опционально)
- **macOS** — `.dmg` + `.zip` (Apple Silicon arm64 + Intel x64, нотаризация Apple)
- **Linux** — `.AppImage`, `.deb`

Артефакты публикуются на [GitHub Releases](https://github.com/Chistovik92/Harness/releases) при создании тега `v*`.
