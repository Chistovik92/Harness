# Установка DeepSeek Harness Desktop

## Windows

1. Скачайте `DeepSeek Harness-<версия>.exe` (установщик NSIS, x64) со страницы [Releases](../../releases).
2. Запустите установщик и следуйте мастеру. Приложение установится в `%LOCALAPPDATA%\Programs\DeepSeek Harness`.
3. Запустите приложение из меню «Пуск» или ярлыка на рабочем столе.

Обновления: приложение проверяет новые версии автоматически (electron-updater) и предложит перезапуск после загрузки.

## macOS

1. Скачайте `.dmg` (или `.zip`) для вашей архитектуры: `arm64` — Apple Silicon (M1/M2/M3/M4), `x64` — Intel.
2. Откройте `.dmg` и перетащите «DeepSeek Harness» в папку «Программы».
3. При первом запуске: правый клик по приложению → «Открыть» (для неподписанных сборок; подписанные и нотаризированные сборки запускаются обычным способом).

## Linux

- **AppImage**: `chmod +x "DeepSeek Harness-<версия>.AppImage" && ./DeepSeek\ Harness-<версия>.AppImage`
- **deb** (Ubuntu/Debian): `sudo dpkg -i "deepseek-harness_<версия>_amd64.deb"` (или `arm64` для ARM-устройств)
- Бинарные зависимости node-llama-cpp для локальных GGUF-моделей собираются под конкретную платформу при сборке пакета; на ARM64 локальные модели работают через тот же механизм.

## Первый запуск

1. Откройте раздел **«Провайдеры API»** (левое меню) и добавьте ключ одного из провайдеров:
   DeepSeek, OpenAI, Anthropic (Claude), Google (Gemini), Groq, Together, OpenRouter, Hugging Face — либо собственного OpenAI-совместимого провайдера (укажите Base URL).
   Списки моделей загружаются прямо из API провайдера, поэтому доступны актуальные модели.
2. Либо работайте полностью локально: раздел **«Локальные модели»** позволяет войти в Hugging Face и скачать GGUF/ONNX-модель; для запуска ключ не нужен.
3. Выберите провайдера и модель в левой панели и напишите сообщение.

Ключи хранятся зашифрованными (Electron safeStorage) в каталоге данных приложения и не покидают машину, кроме прямых запросов к выбранному провайдеру.

## Сборка из исходников

Требуется Node.js 20+ (для Electron-сборки используется npm, не pnpm):

```bash
npm install
npm run typecheck   # проверка типов
npm test            # unit-тесты (vitest)
npm run build       # сборка renderer + electron
npm run package:win # инсталлятор Windows (package:mac / package:linux на соответствующих ОС)
```
